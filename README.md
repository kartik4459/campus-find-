# campus-find-
CampusFind is a college-level project developed as part of our BEE (Backend Engineering) class. It is a campus lost-and-found platform designed to help students report lost items, post found items, and connect with others to recover their belongings.

Features
Report lost and found items
Browse and search item reports
Filter reports by category, location, and status
Submit claims for reported items
Chat and notifications
Backend API for managing application data


Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB Atlas
Version Control: Git and GitHub

Prerequisites
Node.js and npm
A MongoDB Atlas account

Project Purpose
This project was developed to apply backend engineering concepts through a practical application involving API development, database integration, and data management.
