# CampusFind — Campus Lost & Found System

CampusFind is a web-based platform that helps students report lost and found items on campus and connect with their potential owners.

## Features
- Report lost and found items.
- Match lost reports with found items.
- Submit ownership claims using hidden identifying details.
- Communicate through the chat system.
- Receive notifications about reports and claims.

## Technologies Used
- HTML
- CSS
- JavaScript
## Project Purpose
This project aims to make the campus lost-and-found process easier, more organized, and more efficient for students.
